**Lumen Code 0.6.0 — песочница, машина времени, микроконтроллеры, tree-sitter, Claude по подписке**

- **Песочница скетчей.** Команда «Песочница: выполнять код на лету» (и кнопка в строке состояния): Python, JavaScript, TypeScript и Lua выполняются после каждой паузы в наборе, значения переменных, вывод и ошибки появляются справа от строк (Inlay Hints). JS/TS идут в изолированном Worker, Python и Lua — обычными процессами с вашими правами (без изоляции), поэтому песочница включается явно и только в доверенной папке. Графики пока не отображаются.
- **Машина времени.** Версии файла сохраняются при сохранении и через 15 секунд после паузы в наборе: SQLite + zstd-дельты, до 300 версий на файл. Команды «Машина времени: сравнить / вернуть прошлую версию».
- **Микроконтроллеры.** Монитор COM-порта, плоттер (`a:1 b:2` или `1,2,3`), `arduino-cli` (платы, компиляция, загрузка) и `esptool` (запись `.bin`). Проверен список портов и разбор данных; на реальной плате не пробовалось.
- **tree-sitter.** Структурный поиск и замена по запросам tree-sitter (Python, JS, TS, Rust, Go, Lua). ИИ-агент получил инструмент `file_outline`, а большой файл уходит в контекст как контур сигнатур плюс начало, а не обрезанным текстом.
- **MCP.** «MCP: подключить инструмент…»: SQLite, PostgreSQL, файлы, граф знаний, fetch, документация (Context7), браузер (Playwright) и Claude Code (`claude mcp serve`). Каждый сервер запускается как программа и подтверждается перед подключением.
- **Claude по подписке.** Новый провайдер «Claude Code (подписка)» в чате: работает через официальный `claude -p` и ваш вход `claude auth login`. Только чат, без инструментов агента.
- **Открыть с помощью.** При первом запуске Lumen Code попадает в список «Открыть с помощью» для известных расширений (`.txt`, `.md`, `.py`…) и добавляет пункт в контекстное меню Проводника (только HKCU). Отменяется на странице ассоциаций.
- **Безопасность.**
  - Workspace Trust: `.lumen/settings.json` чужой папки не может запускать программы (языковые серверы, MCP, команды запуска, интерпретатор, отладчики) и ослаблять подтверждения ИИ, пока вы не доверите папку; `AGENTS.md` и `.lumen/rules.md` тоже учитываются только в доверенной папке.
  - Плагины: согласие нужно всем сторонним плагинам, даже без заявленных прав, и спрашивается заново при изменении кода (SHA-256); установка только по https. Плагины по-прежнему не изолированы от редактора.
  - ИИ-агент всегда спрашивает перед чтением `.env`, ключей и подобных файлов; результаты инструментов помечены как недоверенные данные.
  - Git вызывается с `core.fsmonitor=false` и `protocol.ext.allow=never`, чтобы конфиг клонированного репозитория не запускал программы.

Проверено: тесты (Rust 32, TypeScript 45) и headless smoke-тест собранной программы, включая песочницу на Python, машину времени и tree-sitter. Не проверялось: Lua-раннер песочницы (Lua не установлен на машине сборки), TypeScript в песочнице, работа с реальной платой, arduino-cli/esptool, регистрация в Проводнике и сам чат через подписку целиком в интерфейсе.
