**Lumen Code 0.2.0 — запуск, отладка, шаблоны, плагины**

- **Запуск любых файлов** (Ctrl+F5 / кнопка ▶): Python, Java, Kotlin, C, C++, C#, Go, Rust, JS/TS, PHP, Ruby, Perl, Lua, R, Dart, Julia, Elixir, Haskell, Zig, PowerShell, bat, Bash, GDScript, HTML/SVG в браузере. Нет компилятора — установка через winget или ссылка на загрузку, PATH обновляется на лету.
- **Отладчик (DAP):** точки останова (условные, лог-точки), шаги, переменные, наблюдение, стек, консоль отладки. Python из коробки (debugpy ставится по запросу), другие адаптеры подключаются настройкой `debug.adapters`. Меню «Запуск» и привычные клавиши F5/F9/F10/F11.
- **Новый файл из шаблона** (30+ типов, с пометкой, чего нет на ПК), **новый проект** (9 заготовок), свои шаблоны.
- **Плагины:** встроенные — сниппеты для 15 языков, цвета в коде, git blame, TODO-список, закладки, калькулятор, 14 дополнительных тем; в каталоге — Lorem Ipsum, быстрые заметки, эмодзи.
- **Интерфейс:** структура файла (Outline), кнопки запуска и отладки в заголовке, сравнение двух файлов, «Восстановить закрытую вкладку» (Ctrl+Shift+T), открытие файла программой по умолчанию.

Не проверено вручную: отладчики кроме Python, установка компиляторов через winget на чистой системе.
