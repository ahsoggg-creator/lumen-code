**Lumen Code 0.4.0 — языковые серверы и удобный «Новый файл»**

- **Языковые серверы (LSP).** Автодополнение, подсказки по аргументам, всплывающая справка, переход к определению, поиск ссылок, переименование по проекту, быстрые исправления, форматирование и ошибки «на лету» для **Python** (basedpyright), **Rust** (rust-analyzer), **Go** (gopls), **C/C++** (clangd) и **Lua**. Если сервера нет, редактор предложит поставить его в один клик — с показом точной команды и только после вашего подтверждения. Свой сервер подключается настройкой `lsp.servers`. [Подробнее](LSP.md).
- **«Новый файл» (Ctrl+N) теперь спрашивает, что создать:** пустой документ, текстовый документ или любой из **установленных на этом компьютере** языков (Python, Java, Rust, JavaScript, …). Ещё не установленные языки и свои шаблоны — в пункте «Другие языки и свои шаблоны…». Пустая вкладка без вопросов — `Ctrl+Alt+Shift+N`.
- **Безопасность ИИ-агента.** Исправлен обход ограничения рабочей папки: путь вида `..\..\файл` проходил проверку. Теперь пути нормализуются и сравниваются по реальному расположению (симлинки и junction тоже).
- **Тесты.** Добавлены тесты интерфейса (Vitest) и проверка LSP на настоящем сервере; в smoke-тест добавлены проверки LSP и нового диалога.

**Обновление с 0.3.0:** репозиторий переехал на `github.com/ahsoggg/lumen-code`, а 0.3.0 принимает загрузки только со старого адреса, поэтому автообновление из неё, скорее всего, откажется работать. Скачайте `LumenCode.exe` со страницы релизов один раз вручную — дальше обновления снова будут автоматическими.

Не проверено вручную: установка серверов Rust, Go, C/C++ и Lua (проверен Python); LSP-проверки автоматизированы только для Python.
