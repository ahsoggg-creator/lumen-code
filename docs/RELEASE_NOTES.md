Первый публичный выпуск Lumen Code.

**Что внутри**
- Редактор на Monaco: мультикурсор, миникарта, сворачивание, sticky scroll, diff, форматирование.
- 10 тем, акцент, шрифты, масштаб, свой CSS, свои цвета, полная настройка через UI и JSON.
- Проводник, поиск по проекту с заменой, Git (индекс, коммит, diff, ветки, push/pull, полоски изменений), терминал.
- Python: выбор интерпретатора, venv, управление пакетами pip, запуск файла (F5).
- Плагины на JavaScript и каталог плагинов; ИИ-чат с агентом (Claude, OpenAI, Ollama и любые OpenAI-совместимые) и запуск CLI-агентов.
- Обновления: «Справка → Проверить обновления», загрузка с проверкой SHA-256.

**Установка:** скачайте `LumenCode.exe` и запустите. Нужен WebView2 (есть в Windows 11).

**Не проверено вручную в этом выпуске:** работа с реальными API ИИ-провайдеров (нужны ключи), push/pull с удалёнными репозиториями.
