**Lumen Code 0.7.1 — «Открыть в Lumen Code» в Проводнике и программа по умолчанию**

- **Пункты в меню Проводника восстанавливаются сами.** При каждом запуске Lumen Code проверяет, что он есть в «Открыть с помощью» для известных расширений (`.txt`, `.md`, `.py` и других) и что в контекстном меню файлов, папок и пустого места папки есть пункты «Открыть в Lumen Code» / «Открыть папку в Lumen Code», и что они указывают на эту программу. Если записи пропали (переустановка, перенос, чистка реестра), они возвращаются. Кнопка «Удалить» на странице ассоциаций отключает это (включается снова кнопкой «Применить»).
- **Программа по умолчанию.** Для расширений, которые не занял никто другой, Lumen Code становится программой по умолчанию. Если расширение уже закреплено за другой программой (например, `.txt` за VS Code), Windows не разрешает менять это из программ: появится уведомление с кнопкой в «Приложения по умолчанию».
- **Windows 11.** Новое компактное меню Проводника показывает такие пункты только в «Показать дополнительные параметры» (`Shift+F10`); в классическом меню они сразу на виду.
- **Исправлено.** Автоматический тест установленной программы мог стирать эти записи в реестре пользователя; теперь он работает в отдельной ветке реестра.

Проверено: тесты (Rust 45, TypeScript 67), включая запись, чтение, замену и удаление регистрации в отдельной ветке реестра, и headless smoke-тест. Не проверялось: вид пунктов в Проводнике после обновления и смена программы по умолчанию на другой машине.
