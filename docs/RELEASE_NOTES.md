**Lumen Code 0.7.0 — просмотр баз и CSV, HTTP-клиент, декодер падений ESP32, замеры запуска, закрытые уязвимости**

**Новое**
- **Просмотр SQLite и CSV.** Файлы `.sqlite`, `.sqlite3`, `.db`, `.db3` открываются таблицей: выбор таблицы, фильтр по всем столбцам, сортировка по клику на заголовок, постраничный показ, правка ячейки двойным щелчком (`Ctrl+Delete` в поле — записать NULL) и окно SQL (`Ctrl+Enter`). Запросы `SELECT` идут в режиме «только чтение», изменяющие запросы просят подтверждение. `.csv` и `.tsv` тоже открываются таблицей (разделитель определяется сам, числа сортируются как числа) с кнопкой «Открыть как текст». `.parquet` пока не поддерживается.
- **HTTP-клиент.** В файлах `.http` и `.rest` над каждым запросом появляется «▶ Отправить запрос» (или `Ctrl+Alt+R`). Запрос уходит через Rust-бэкенд, без ограничений CORS; ответ открывается в соседнем сплите: статус, время, размер, заголовки, подсвеченное тело. Поддерживаются `###`, переменные `@name = value` и `{{name}}`, `{{$guid}}`, `{{$timestamp}}`, тело запроса, продолжение строки запроса. WebSocket пока нет.
- **Декодер падений ESP32/Arduino.** Монитор порта сам находит строки `Backtrace:` и регистры `PC/MEPC/RA`, расшифровывает адреса через `addr2line` вашего ядра (Arduino15, PlatformIO, ESP-IDF) и `.elf` текущей сборки и показывает функции со ссылками `файл:строка`, по клику открывающими нужную строку в редакторе. `.elf` ищется в `build/` и `.pio/` или указывается вручную.
- **OTA по Wi-Fi.** Кнопка «OTA по Wi-Fi» в панели прошивки: платы находятся через `arduino-cli board list` (mDNS), либо адрес вводится вручную; прошивка через `arduino-cli compile --upload --protocol network`, пароль OTA по запросу.
- **Замер запуска.** После «Запустить без отладки» (`Ctrl+F5`) в строке состояния показываются память, загрузка процессора и мини-график запущенной программы, а по завершении — время выполнения и пик памяти (точность около 0,25 с). F5 с отладчиком не измеряется.

**Безопасность**
- **Монитор порта.** Строка не длиннее 4 КБ, события в интерфейс идут не чаще 60 раз в секунду, а при всплеске остаётся только последние 64 КБ (с пометкой, сколько пропущено); плоттер обрабатывает не больше 200 строк за кадр.
- **Машина времени.** Файлы `.env*`, `.pem`, `.key`, `.pfx`, `.p12`, `id_rsa`, `credentials`, `secret*` и файлы крупнее 5 МБ не записываются. Команды «очистить историю этого файла» и «очистить всю историю».
- **Песочница скетчей.** Python и Lua запускаются в Windows Job Object: следующий запуск убивает предыдущий со всеми дочерними процессами, лимит памяти 512 МБ и 32 процессов, вывод обрезается до 1 МБ, а закрытие редактора завершает всё запущенное.
- **MCP.** Список `ai.mcpServers` по-прежнему не читается из `.lumen/settings.json` проекта без доверия к папке. Вызовы MCP-инструментов, которые пишут, удаляют или запускают (`DROP`, `DELETE`, `write_*`, пути с `..` и т. п.), теперь спрашивают подтверждение даже при включённом автоподтверждении команд.

**Исправлено**
- Чат «Claude по подписке» в режиме агента теперь работает прямо в открытой папке проекта инструментами Claude Code (чтение всегда, правка и команды по вашим галочкам «Права агента»); без открытой папки модель подсказывает её открыть.

Независимое ревью нашло и помогло исправить двойное закрытие Job-handle в песочнице, лог монитора без ограничения по размеру, пароль OTA в журнале и обход подтверждений у camelCase-инструментов MCP.

Проверено: тесты (Rust 44, TypeScript 67) и headless smoke-тест собранной программы, включая просмотр SQLite и CSV, HTTP-клиент на живом запросе, убийство бесконечного цикла песочницей и замер запуска. Не проверялось: плата и `arduino-cli`/`esptool`, расшифровка на реальном `.elf` (проверен только разбор и поиск адресов), OTA, Lua-раннер, сам чат через подписку в интерфейсе.
