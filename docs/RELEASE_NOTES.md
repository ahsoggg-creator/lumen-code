**Lumen Code 0.3.0 — ассоциации файлов и расширения VS Code**

- **Открывайте файлы в Lumen Code из проводника.** «Файл → Ассоциации файлов…»: отметьте `.py` и другие типы — они появятся в «Открыть с помощью»; пункт «Открыть в Lumen Code» для файлов и папок в контекстном меню; кнопка в системные «Приложения по умолчанию». Без прав администратора. Повторный запуск открывает файл в уже работающем окне.
- **Расширения VS Code из Open VSX.** Панель «Расширения VS Code»: поиск, установка, установка из `.vsix`. Работают цветовые темы (импортируются целиком), сниппеты, описания языков и TextMate-подсветка для языков, которых нет в редакторе. Расширения с исполняемым кодом (`extension.js`) не запускаются — это отмечено в списке.

Не проверено вручную: «Открыть с помощью» и двойной щелчок в самом проводнике Windows (проверена запись/удаление ключей реестра), массовая совместимость расширений (проверены тема Dracula и грамматика Nix).
