**Lumen Code 0.5.1 — установщик**

- **Установщик `LumenCode-Setup.exe`.** Теперь на странице релиза рядом с переносимым `LumenCode.exe` лежит установщик: ставит программу в вашу папку пользователя (права администратора не нужны), создаёт ярлык в меню «Пуск» и запись для удаления в «Приложениях». Переносимый `LumenCode.exe` остаётся и работает как раньше.
- **Автообновление через установщик.** Если программа установлена установщиком, обновление скачивает новый `LumenCode-Setup.exe`, проверяет его SHA-256 по `SHA256SUMS.txt`, тихо переустанавливает программу и запускает её снова. Переносимая версия обновляется заменой файла, как раньше.

Обновление с 0.5.0 на 0.5.1 идёт заменой файла (в 0.5.0 установщика ещё нет); установщик можно взять со страницы релиза. Прежние изменения 0.5.0 описаны в [релизе 0.5.0](https://github.com/ahsoggg/lumen-code/releases/tag/v0.5.0).

Проверено вручную: тихая установка и удаление установщика и команда «переустановить и запустить заново». Саму цепочку «обновление из программы» можно будет проверить только на следующем релизе, поскольку 0.5.0 о установщике ещё не знает.
