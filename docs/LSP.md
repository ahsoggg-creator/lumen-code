# Языковые серверы (LSP)

Для JavaScript, TypeScript, JSON, CSS и HTML автодополнение и проверка встроены в Monaco. Для остальных языков Lumen Code
подключает **языковые серверы** — отдельные программы, которые понимают код: они дают то же, что в VS Code.

| Что работает | Как вызвать |
|---|---|
| Ошибки и предупреждения «на лету» | подчёркивание в коде, панель «Проблемы» |
| Автодополнение, документация к пунктам | печатайте, `Ctrl+Пробел` |
| Подсказка по аргументам функции | `(` и `,` |
| Всплывающая справка | наведите курсор |
| Переход к определению / типу / реализации | `F12`, `Ctrl+Щелчок` |
| Все ссылки на символ | `Shift+F12` |
| Переименование по всему проекту | `F2` |
| Символы файла | сервер передаёт их Monaco (поиск символа в файле); боковая панель «Структура» пока строится по шаблонам |
| Форматирование документа / выделения | `Shift+Alt+F` (если сервер умеет) |
| Быстрые исправления | лампочка / `Ctrl+.` |

## Встроенные серверы

| Язык | Сервер | Откуда берётся |
|---|---|---|
| Python | [basedpyright](https://docs.basedpyright.com/) | `pip install basedpyright` в выбранный интерпретатор |
| Rust | rust-analyzer | `rustup component add rust-analyzer` |
| Go | gopls | `go install golang.org/x/tools/gopls@latest` |
| C / C++ | clangd | `winget install LLVM.LLVM` |
| Lua | lua-language-server | `winget install LuaLS.lua-language-server` |

Если сервера нет, при открытии файла появится уведомление **«Установить»** — показывается точная команда, и она
выполняется только после вашего подтверждения. «Не предлагать» запоминает отказ (настройка `lsp.dismissed`).

Состояние сервера видно в строке состояния справа (например, `basedpyright`). Нажмите на него, чтобы перезапустить
сервер или открыть журнал. Те же действия есть в палитре: «LSP: перезапустить языковые серверы», «LSP: показать журнал».

Сервер для Python использует интерпретатор, выбранный в панели Python (виртуальное окружение проекта подхватывается),
и перезапускается при его смене.

## Настройка

В `settings.json`:

```jsonc
{
  "lsp.enabled": true,            // выключить всё одним переключателем
  "lsp.servers": {
    // изменить встроенный сервер — по его id: python, rust, go, clangd, lua
    "python": { "command": "pyright-langserver", "args": ["--stdio"] },
    "go": { "disabled": true },
    // настройки, которые сервер запрашивает у редактора (workspace/configuration)
    "rust": { "settings": { "rust-analyzer": { "check": { "command": "clippy" } } } },
    // добавить свой сервер: id, languages (id языков Monaco) и command
    "zls": { "command": "zls", "languages": ["zig"] }
  }
}
```

Если задан свой `command`, Lumen Code не пытается устанавливать этот сервер сам.

## Ограничения

- Документы передаются серверу целиком (полная синхронизация) — на очень больших файлах это заметно медленнее инкрементальной.
- Переименование в файлах, не открытых в редакторе, записывается прямо на диск (в открытых — через историю правок, `Ctrl+Z` работает).
  Операции над файлами (создание, переименование, удаление), которые иногда требует сервер, пока не поддерживаются.
- Один сервер на язык и папку проекта; файлы вне папки проекта получают отдельный сервер с корнем в своей папке.
- Файлы без пути на диске (безымянные вкладки) серверами не обслуживаются.
