# Чем актуален VS Code и что из этого повторено в Lumen Code

Источники: [Stack Overflow Developer Survey 2026](https://visualstudiomagazine.com/articles/2026/10/06/stack-overflow-2026-survey-vs-code-leads-visual-studio-takes-third.aspx),
[релиз VS Code 1.109](https://www.gitclear.com/open_repos/Microsoft/vscode/release/1.109.0),
[про мультиагентную разработку](https://letsdatascience.com/news/vs-code-enables-multi-agent-development-support-039457ab).
Остальное — известные возможности редактора; отдельно сверялся только поиском по новостям (не по полным release notes).

## Почему VS Code до сих пор №1

- Опрос Stack Overflow 2026: VS Code — 70,9 % (Cursor — 14,9 %, Zed — 11,4 %). Выбирают из-за **экосистемы расширений**, скорости и бесплатности.
- Главный тренд 2025–2026: **агенты прямо в редакторе** — agent mode, MCP-серверы, параллельные сессии агентов (Claude, Codex, Copilot), навыки агентов.
- Остальное, за что его ценят: терминал, Git, отладчик, Remote-SSH/WSL/контейнеры, Live Share, ноутбуки, синхронизация настроек.

## Где Lumen Code сознательно отличается

- **Размер и скорость.** Не Electron: движок страницы — системный WebView2, бэкенд на Rust. Один файл, без установки.
- **Ленивая загрузка.** Monaco, xterm, Git, Python, ИИ грузятся при первом использовании; языки Monaco — по требованию.
- **Настройка без расширений:** любой CSS, любые цвета, сторона панели, масштаб, шрифты, скругление, анимации.
- **Честность про ограничения:** отладчика и LSP нет, MCP нет, плагины выполняются с правами редактора.

## Что логично добавить следующим

1. MCP-клиент (stdio/http) для чат-агента.
2. LSP-мост (запуск языковых серверов, `pylsp`/`rust-analyzer`) — через Rust.
3. Debug Adapter Protocol для Python (`debugpy`).
4. tasks.json и вывод проблем из команд.
