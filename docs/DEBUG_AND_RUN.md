# Запуск и отладка

## Запуск файлов (Ctrl+F5, кнопка ▶)

Тип файла определяется по расширению. Если нужной программы нет на ПК, Lumen Code предложит **установить через winget** или **скачать с официального сайта**, затем сам обновит PATH — перезапускать редактор не нужно.

| Тип | Что выполняется |
|---|---|
| Python | выбранный интерпретатор (`.venv` проекта и т. п.) |
| Java | `java Файл.java` |
| Kotlin | `kotlinc` → `java -jar` |
| C / C++ | `gcc` / `g++` → запуск `.exe` |
| C# | `dotnet run` (проект) или `dotnet run файл.cs` |
| Go, Rust | `go run` / `cargo run` (если есть `go.mod` / `Cargo.toml`), иначе `rustc` |
| JavaScript / TypeScript | `node` / `npx tsx` |
| PHP, Ruby, Perl, Lua, R, Dart, Julia, Elixir, Haskell, Zig | соответствующий интерпретатор |
| PowerShell, .bat, Bash | оболочка |
| GDScript | `godot --headless -s` |
| HTML, SVG | открываются в браузере |
| Markdown | предпросмотр |

Свои команды — настройка `run.commands` (по расширению или языку, строка или цепочка шагов):

```json
{ "run.commands": { "nim": "nim c -r \"${file}\"", "c": ["gcc \"${file}\" -O2 -o \"${out}\"", "\"${out}\""] } }
```

Переменные: `${file}` `${dir}` `${name}` `${out}` `${python}` `${workspace}`.

## Отладчик

Работает по **Debug Adapter Protocol**. Из коробки — Python (через `debugpy`; если модуля нет, редактор предложит поставить его в выбранный интерпретатор).

| Действие | Клавиши |
|---|---|
| Начать отладку / продолжить | F5 |
| Запустить без отладки | Ctrl+F5 |
| Остановить / перезапустить | Shift+F5 / Ctrl+Shift+F5 |
| Шаг с обходом / внутрь / наружу | F10 / F11 / Shift+F11 |
| Пауза | F6 |
| Точка останова | F9 или щелчок слева от номера строки |
| Условная точка / лог-точка | правый щелчок слева от номера строки |

Что есть: точки останова (условные, лог-точки; переживают правки текста и перезапуск), подсветка текущей строки, панель «Запуск и отладка» (переменные с раскрытием, наблюдение, стек вызовов, список точек), консоль отладки с вычислением выражений на паузе, остановка на исключениях (`debug.exceptions`). Программа запускается в обычном терминале, поэтому `input()` работает.

### Свой отладчик

Любой адаптер DAP, говорящий по stdio, подключается настройкой `debug.adapters` (ключ — id языка):

```json
{
  "debug.adapters": {
    "go": {
      "kind": "stdio", "command": "dlv", "args": ["dap"],
      "adapterID": "go", "request": "launch",
      "body": { "mode": "debug", "program": "${file}" }
    }
  }
}
```

Адаптеры, которые слушают порт и запускаются в терминале (как debugpy), описываются `"kind": "tcp-terminal"` с полем `terminal` (команды) и подстановкой `${port}`.
Кроме Python, отладчики в этой версии не проверялись — формат подходит для `dlv`, `lldb-dap`, `netcoredbg`, но это ваша настройка.

## Новый файл и проект

- **Файл → Новый файл из шаблона…** (Ctrl+Alt+N, а также в контекстном меню папки): языки сгруппированы, у отсутствующих на ПК стоит пометка. Выбрав такой язык, можно создать файл всё равно, установить программу или открыть страницу загрузки.
- **Свои шаблоны:** «Файл → Сохранить как шаблон…», либо положите файлы в папку шаблонов (команда «Открыть папку своих шаблонов»). В тексте можно использовать `${class}` — имя файла как имя класса.
- **Файл → Новый проект…:** Python, сайт, Node.js, Java, C, C++, Rust (`cargo new`), Go, C# (`dotnet new`).
- **Запуск → Языки и компиляторы…:** что установлено, установка в один клик.
