# Расширения VS Code в Lumen Code

Источник — реестр **Open VSX** (open-vsx.org). Реестр Microsoft Marketplace сторонним редакторам использовать нельзя, поэтому его нет. Часть расширений есть и там, и там.

**Установка:** панель «Расширения VS Code» (значок-коробка, `Ctrl+Shift+P` → «Расширения VS Code: управление») — поиск и кнопка «Установить»; либо «Установить из .vsix…». Расширения лежат в `%APPDATA%\LumenCode\vscode-extensions`.

## Что работает

| Вклад расширения | Что происходит |
|---|---|
| `themes` — цветовые темы | Импортируются целиком: цвета редактора и правила подсветки, интерфейс окрашивается по палитре темы. Выбор: `Ctrl+K Ctrl+T` (пометка «(VS Code)») |
| `snippets` | Сниппеты появляются в автодополнении своего языка |
| `languages` | Регистрируются язык, расширения файлов, комментарии, скобки, автозакрытие, сворачивание |
| `grammars` — TextMate | Подсветка языков, которых нет в Monaco (загружается лениво, при открытии файла такого языка). Для уже встроенных языков по умолчанию не заменяет подсветку — включается настройкой `vscode.overrideBuiltin` |

## Что не работает

- Всё, что требует кода расширения: `extension.js` (команды, языковые серверы, отладчики, Copilot-подобные помощники, вебвью). В списке такие расширения помечены «код не выполняется».
- Иконочные темы, продуктовые иконки, пользовательские редакторы, ноутбуки.
- Селекторы-потомки в правилах тем (`a b`) пропускаются.

Выключить расширение — переключатель в списке (полностью вступает в силу после перезагрузки окна). Удаление — «Удалить».

Для настоящих расширений Lumen Code есть свой API: [PLUGINS.md](PLUGINS.md).
