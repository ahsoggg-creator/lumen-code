# Lumen Code

[English](README.en.md) · [Русский](README.md)

Лёгкий, быстрый и полностью настраиваемый редактор кода для Windows — в духе VS Code, но на Tauri + Rust вместо Electron. Один `.exe`, без установки.

- **Движок редактора — Monaco** (тот же, что в VS Code): мультикурсор, миникарта, сворачивание, sticky scroll, diff, автодополнение для JS/TS/JSON/CSS/HTML.
- **Оформление.** 10 тем (Catppuccin, Tokyo Night, Dracula, One Dark, Nord, Gruvbox, Rosé Pine, Solarized, GitHub Light…), акцентный цвет, шрифты, масштаб интерфейса, скругления, сторона панелей, анимации. Любой внешний вид — через **свой CSS** и JSON-переопределение цветов.
- **Настройка.** Страница настроек с поиском и `settings.json` (с подсказками), настройки проекта `.lumen/settings.json`, все сочетания клавиш переназначаются (в том числе цепочки вроде `Ctrl+K Ctrl+S`).
- **Лёгкость.** Бэкенд на Rust; интерфейс без фреймворка; Monaco, терминал, Git, Python и ИИ грузятся при первом обращении; дерево файлов виртуализировано; поиск параллельный; слежение за файлами пакетное.
- **Плагины.** JavaScript-модули в `%APPDATA%\LumenCode\plugins`: команды, клавиши, панели, статус-бар, темы, агенты ИИ. Каталог и установка по ссылке. [Документация](docs/PLUGINS.md).
- **ИИ-агенты.** Чат с режимом агента (читает файлы, ищет, правит, запускает команды — каждое действие подтверждается). Провайдеры: Anthropic, OpenAI, OpenRouter, DeepSeek, Groq, Gemini, **Ollama / LM Studio** и любой OpenAI-совместимый. Ключи — в хранилище учётных данных Windows. Плагины могут добавлять своих агентов; есть кнопки запуска Claude Code, Codex, Gemini CLI, Aider в терминале.
- **Python.** Панель выбора интерпретатора (py-launcher, PATH, venv проекта, conda), создание `.venv`, список пакетов, установка/удаление/обновление pip (pyautogui, requests, numpy… — одним кликом), `requirements.txt`, F5 — запуск файла. Выбранный Python подключается к терминалу.
- **Запуск и отладка.** Ctrl+F5 запускает файл любого из ~25 типов (Python, Java, C/C++, C#, Go, Rust, JS/TS, PHP, Lua, HTML в браузере…); нет компилятора — предложит установить через winget или скачать. Отладчик (F5, точки останова, шаги, переменные, наблюдение, стек) — Python из коробки, остальные через DAP-настройку. [Подробнее](docs/DEBUG_AND_RUN.md).
- **Новые файлы и проекты.** «Новый файл из шаблона» (30+ типов с пометкой, чего нет на ПК), «Новый проект», свои шаблоны.
- **Файлы из проводника.** «Файл → Ассоциации файлов…» — `.py` и любые другие типы открываются в Lumen Code (и пункт в контекстном меню), без прав администратора; открытие идёт в уже запущенное окно.
- **Расширения VS Code.** Поиск и установка из Open VSX или из `.vsix`: цветовые темы, сниппеты, языки и TextMate-подсветка. Расширения с кодом не запускаются. [Подробнее](docs/VSCODE_EXTENSIONS.md).
- **Привычные возможности VS Code:** палитра команд, быстрый переход к файлу, Git, терминал, поиск и замена по проекту, разделение редактора, превью-вкладки, навигационная цепочка, полоски изменений Git, Problems, режим концентрации, предпросмотр Markdown, кодировки (Win-1251 и др.), восстановление сессии.
- **Автообновление.** «Справка → Проверить обновления»: если вышла новая версия — предложит скачать; файл проверяется по SHA-256 из `SHA256SUMS.txt` и заменяет текущий. Ежедневная фоновая проверка отключается в настройках.

Подробный разбор возможностей VS Code и что повторено: [docs/VSCODE_ANALYSIS.md](docs/VSCODE_ANALYSIS.md).

## Установка

Скачайте `LumenCode.exe` из [Releases](https://github.com/ahsoggg/lumen-code/releases) и запустите. Нужен WebView2 (есть в Windows 11 и новых Windows 10). Для Git и Python — установленные `git` и Python.

## Сборка

Нужны Rust, Node.js 22+.

```powershell
npm ci
npx tauri build --no-bundle      # src-tauri\target\release\lumen-code.exe
cd src-tauri; cargo test         # тесты бэкенда
```

Выпуск: поднять версию в `src-tauri/Cargo.toml` и `tauri.conf.json`, обновить `docs/RELEASE_NOTES.md`, поставить тег `vX.Y.Z` — GitHub Actions соберёт `LumenCode.exe` и `SHA256SUMS.txt`.

## Файлы и приватность

- Конфигурация: `%APPDATA%\LumenCode` (`settings.json`, `custom.css`, `plugins\`, `sessions\`).
- Сеть: запросы к `api.github.com` (обновления), к выбранному ИИ-провайдеру, к `pypi.org` (описание пакета) и то, что делают плагины и pip. Телеметрии нет.

## Ограничения

Отладчик из коробки только для Python, нет LSP для всех языков, нет MCP, нет Remote-SSH, плагины несовместимы с расширениями `.vsix`, плагины не изолированы от редактора. Только Windows.
